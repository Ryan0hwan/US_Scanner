# 미너비니 VCP 검색기

S&P 500 + 관심종목(약 680개)을 매일 장 마감 후 훑어서, **미너비니 트렌드 템플릿**을 통과하고 **VCP(변동성 수축) 베이스**를 만든 종목을 디스코드로 보냅니다. **한국 시각 평일 아침 07:20쯤** 도착합니다.

## 조건

| # | 조건 | 기준 |
|---|---|---|
| 1 | 52주 고가 근처 | 52주 고가 대비 −25% 이내 |
| 2 | 바닥을 다짐 | 52주 저가 대비 +25% 이상 |
| 3 | 정배열 | 50일 > 150일 > 200일선 |
| 4 | 장기선 위 | 종가가 150일·200일선 위 |
| 5 | 200일선 상승 | 1개월 전보다 높음 (몇 개월째 상승 중인지 진단에 표시) |
| 6 | **VCP 베이스** | 아래 설명 |
| 7 | 상대강도 | RS 90 이상 (IBD 방식: 3개월 ×2 + 6·9·12개월, 스캔 대상 안에서 백분위) |

### 6. VCP 베이스는 이렇게 찾습니다

1. **베이스 시작점**: 최근 9개월(180거래일) 안의 최고가. 최소 3주(15거래일) 이상 지난 고점이어야 합니다.
2. **수축 찾기**: 그 고점부터 3% 이상 반전한 고점·저점(스윙)을 이어서, 각 눌림 폭(고점→저점 %)을 계산합니다. 가로 박스든 **삼각수렴**(고점이 낮아지고 저점이 높아짐)이든 같은 방법으로 잡힙니다.
3. **VCP 판정** (모두 충족):

| 항목 | 기준 |
|---|---|
| 수축 횟수 | 2회 이상 (T2+) |
| 첫 수축 | 40% 이하이고, 베이스 안에서 가장 깊어야 함 |
| 마지막 수축 | 12% 이하이고, 첫 수축의 60% 이하 |
| 점점 줄어듦 | 뒤쪽 수축들의 평균이 앞쪽보다 작음 |
| 저점 상승 | 마지막 수축의 저점 ≥ 첫 수축의 저점 |
| 거래량 마름 | 최근 10일 평균 ≤ 50일 평균의 90%, 그리고 마지막 수축 구간 거래량 < 첫 수축 구간 |

4. **피벗** = 마지막 수축이 시작된 고점 (매수 기준선)

## 디스코드 알림

```
📐 미너비니 VCP 검색기 | 2026-10-19 마감
템플릿(1~5·RS 90+) 통과 18개 → VCP 베이스 4개 (🚀 돌파 1 · 🎯 피벗 근접 3)

🚀 VCP 피벗 돌파 (1)
TICKER   RS  고점%  T 수축%            피벗     종가  돌파%  VOL%  D  NAME
VCPB     91   -1.1  4 26/17/10/5      96.66    99.46   +2.9   280  1  🔊VCPB Corp

🎯 VCP 셋업 · 피벗 근접 (3)

⏳ VCP 형성 중 · 아직 덜 조여짐 (1)

S12      81   -4.4 25/14/14          56.05     +3.5   100  수축+거래량 S12 Corp

📋 템플릿은 통과, VCP는 아님 — 이유별 (괄호는 RS)
· 마지막 눌림이 아직 큼 (15~20% 이상) [6]: NVDA(99) AVGO(97) ...
· 거래량이 안 마름 [3]: ...
· 베이스 없음 (고점 갱신 중이거나 3주 미만) [5]: ...
```

| 섹션 | 뜻 | 할 일 |
|---|---|---|
| 🚀 돌파 | 최근 3거래일 안에 피벗 위로 마감. 🔊 = 돌파일 거래량이 50일 평균의 140% 이상 | 🔊 있는 종목 우선. 피벗 대비 +5% 넘게 올랐으면 추격 금지 |
| 🎯 피벗 근접 | VCP 완성, 피벗 아래 8% 이내 | 관심종목에 넣고 피벗 돌파 알림 설정 |
| ⏳ 형성 중 | VCP 모양(첫 눌림이 가장 깊고, 저점이 높아짐)은 갖췄지만 마지막 눌림이 아직 12~20%이거나 거래량이 덜 마름. 피벗 아래 15% 이내 | 다음 셋업 후보. 남은과제 열을 보고 며칠 지켜보기 |
| 📋 이유별 | 템플릿은 통과했지만 VCP가 아닌 종목을 **탈락 이유별로** 묶음 | 어떤 종목이 왜 빠졌는지 한눈에 확인 |

| 열 | 의미 |
|---|---|
| 수축% | 베이스 안 눌림 폭, 오래된 것 → 최근 (예: 26/17/10/5) |
| T | 점점 줄어든 수축 횟수 |
| 피벗까지 | 현재가에서 피벗까지 남은 % |
| VDU% | 최근 10일 ÷ 50일 평균 거래량. 낮을수록 매도 물량이 말랐다는 뜻 |
| 베이스 | 베이스 길이 (거래일) |
| 🆕 | 오늘 새로 셋업에 들어온 종목 |

돌파 알림은 같은 종목에 10일에 한 번만 보냅니다. 셋업 목록은 매일 전체를 보냅니다.

## 🔍 진단 모드 (종목이 왜 안 잡혔는지 확인)

**평소에는 diagnose 칸을 비워 두세요** (정상 스캔). 특정 종목이 왜 잡히거나 안 잡혔는지 알고 싶을 때만 씁니다.

**Actions → VCP Scanner → Run workflow**를 누를 때 **diagnose** 칸에 티커를 적으면, 스캔 대신 종목별로 7개 조건의 통과 여부와 수축 내역(날짜·가격·깊이)을 보내 줍니다. 관심종목에 없는 티커도 됩니다.

| diagnose 칸 | 동작 |
|---|---|
| (비움) | 정상 스캔 |
| `NVDA` | 오늘 기준 진단 |
| `NVDA,AVGO` | 여러 종목 (쉼표로 구분) |
| `ZETA@2026-01-05` | **과거 날짜 기준** 진단. 예전 교과서 차트가 그 시점에 잡혔을지 확인할 때 (최근 약 1년 이내 날짜) |

```
🔍 ZETA 진단
✅ 1. 52주 고가 대비 -6.0% (기준 -25% 이내)
...
6. 베이스: 2026-06-16 고점부터 89일, 수축 4회
   T1: 2026-06-16 101.03 → 2026-07-13 74.51  -26.2%
   T2: 2026-08-03 98.54 → 2026-08-21 82.49  -16.3%
   ...
❌ 6. VCP 아님: 마지막 수축이 아직 큼 (14% > 12%)
```

내가 VCP라고 본 종목이 안 잡히면 진단 결과를 캡처해서 보여 주세요. 기준값을 그 차트에 맞게 조정할 수 있습니다.

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 (예: `vcp-검색기`) → ⚙ → 연동 → 웹후크 → 새 웹후크 → 채널 확인 → **웹후크 URL 복사**
2. **GitHub**: New repository (이름 예: `vcp-scanner`) → `vcp.py`, `watchlist.txt`, `requirements.txt`, `README.md` 업로드 → Commit
3. **Add file → Create new file** → 이름 `.github/workflows/main.yml` → zip 안의 같은 파일 내용 붙여넣기 → Commit
4. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL`, Secret에 웹후크 주소
5. **Actions → VCP Scanner → Run workflow**로 테스트 (3~5분)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `HIGH_DOWN_PCT` | 25 | 1. 52주 고가 대비 최대 하락률(%) |

| `ZZ_PCT` | 3 | 스윙으로 인정할 최소 반전폭(%). 키우면 큰 수축만, 줄이면 작은 수축까지 셈 |

## 알아둘 점

- **RS 90**은 이 스캐너가 보는 약 680종목 안에서의 순위입니다. IBD는 미국 전체 약 6,000종목 기준이라 숫자가 다를 수 있습니다. 대형주 위주라서 같은 RS 90이라도 IBD보다 조금 더 까다로운 편입니다.
- **실적(EPS·매출) 조건은 들어 있지 않습니다.** 미너비니는 실적 성장을 함께 보니, 후보가 나오면 실적은 직접 확인하세요.
- VCP 모양은 사람마다 보는 기준이 달라서, 자동 판정이 내 눈과 다를 수 있습니다. 진단 모드로 비교하면서 기준값을 맞춰 가는 것을 추천합니다.
