# 실적 플레이 리포트 (무료 옵션 데이터)

Unusual Whales·Bullflow 같은 유료 서비스의 실적 플레이 정보를 **무료 데이터(야후 파이낸스 옵션 체인 + 나스닥 실적 캘린더)** 로 최대한 비슷하게 만든 시스템입니다.

## 언제 오나

| 실행 | 내용 |
|---|---|
| 자동 (평일 한국 07:10) | ① 앞으로 3거래일 안에 실적 발표하는 S&P 500 + 관심종목 목록 ② 그중 시가총액 $20억 이상, 큰 순 최대 10종목 리포트 |
| 수동 | Run workflow → system `earnings` → diagnose에 `HIMS, APP`처럼 넣으면 그 종목만 (실적 일정과 상관없이) |

## 종목마다 오는 내용

| 순서 | 내용 | 유료 화면에서 대응되는 것 |
|---|---|---|
| ① 요약 | 실적 일정(장 시작 전/마감 후), 옵션 예상 변동폭, 과거 평균 반응과 비교, IV 크러시 예상, EPS·매출 예상치, 콜월·풋월·감마 플립·맥스페인, 풋/콜 비율, 오늘 콜·풋 프리미엄 | Earnings Hub, 예상 변동, Flow sentiment, Put to call |
| ② 과거 실적 반응 | 최근 8회 갭%·종가%·EPS 서프라이즈 | Prev. Move |
| ③ 프리미엄 큰 옵션 계약 | 45일 이내 만기, 현재가 ±20% 행사가 중 오늘 거래 금액 큰 순 10개. 🔥 = 거래량 > 미결제약정 (새 포지션 가능성) | Unusual flow |
| ④ GEX 히트맵 그림 | 행사가 × 만기 3개(★ = 실적 반영 첫 만기). 초록 = 플러스 감마, 빨강 = 마이너스 감마 | GEX Heatmap |

## 숫자 읽는 법

| 항목 | 의미 |
|---|---|
| 옵션 예상 변동 | 실적 반영 첫 만기 ATM 스트래들(콜+풋) ÷ 주가. 옵션 시장이 예상하는 실적 후 움직임 폭 |
| 과거 평균 반응 | 지난 실적 다음 날(장 시작 전 발표는 당일) 종가 기준 움직임의 평균 크기. 옵션 예상보다 작으면 옵션이 비싸게 가격 매겨진 것 |
| IV 크러시 | 실적 만기 IV가 다음 만기보다 높으면, 실적 발표 후 IV가 내려가 옵션 가격이 빠짐 |
| 콜월 / 풋월 | 콜 감마 / 풋 감마가 가장 큰 행사가. 보통 저항 / 지지로 봄 |
| 감마 플립 | 전체 감마가 플러스↔마이너스로 바뀌는 가격. 위 = 안정, 아래 = 변동성 확대 |
| 맥스페인 | 실적 만기에 옵션 매수자 손실이 가장 큰 가격 |
| 풋/콜 비율 | 1보다 크면 풋 쪽이 많음 (헤지·하락 베팅) |

## 무료 데이터의 한계 (유료와 다른 점)

- **체결 방향(매수/매도), 스윕, 블록, 멀티레그 전략 구분이 없습니다.** "누가 샀다"는 알 수 없고 "많이 거래됐다"만 압니다.
- **다크풀 체결**, 장중 **순프리미엄 실시간 추이**는 없습니다.
- 미결제약정은 **하루 1회(전날 기준)** 갱신됩니다. GEX는 "딜러가 콜·풋을 판 쪽"이라는 단순 가정으로 계산합니다.
- 야후 옵션 시세는 약 15분 지연입니다.

## 설정 (`earnings.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `AHEAD_DAYS` | 3 | 앞으로 며칠(거래일) 안의 실적 |
| `MAX_TICKERS` | 10 | 자동 리포트 최대 종목 수 |
| `MIN_MCAP` | 20억 달러 | 자동 리포트 최소 시가총액 |
| `EARN_TICKERS` | 없음 | 항상 리포트할 종목 (예: `"HIMS,APP"`) |
| `STRIKE_RANGE` / `MAX_STRIKES` | ±25% / 28줄 | 히트맵 범위 |
| `HIST_N` | 8 | 과거 실적 반응 횟수 |
