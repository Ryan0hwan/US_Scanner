# 강세주 눌림목 스캐너 v2 (마틴 룩 방식, 일봉)

S&P 500 + 관심종목에서 마틴 룩의 공개 방식(스크리너 3종, Lead·Mediocre·Lag 분류, 지지선 겹침 눌림목, 실적 회피)을 일봉 기준으로 옮겼습니다. 한국 시각 23:50(장중)과 07:10(마감 후)에 실행됩니다. 실제 진입(5분봉 박스 돌파)은 장중에 직접 확인하고, 이 시스템은 **후보 · 지지 구간 · 트리거 · 손절가**를 미리 준비합니다.

## 디스코드에 오는 순서

| 순서 | 내용 |
|---|---|
| 1 | **시장 내부 강도**: 전 종목 Lead / Mediocre / Lag 개수와 어제 대비 이동. Lead가 줄고 Lag가 늘면 주의 |
| 2 | **🆕 새로 Lead 진입**: 업종별로 묶음. 같은 업종에서 2종목 이상이면 🔥 (자금 유입 신호) |
| 3 | **✅ 발동 / 🎯 지지 도착 / 📍 접근 중** 눌림목 표 |
| 4 | **⚡ Potent**: 21·50 EMA 위에서 오늘 강하게 오른 종목 (새 강세 후보, 상위 15) |
| 5 | 탈락 단계 집계 (어느 조건에서 많이 빠지는지) |

## 분류 (EMA 배열)

| 분류 | 조건 |
|---|---|
| 🟢 Lead | 9 EMA > 21 EMA > 50 EMA |
| 🟡 Mediocre | 그 사이 |
| 🔴 Lag | 9 EMA < 21 EMA < 50 EMA |

## 눌림목 조건 (순서대로 걸러짐)

| 단계 | 조건 |
|---|---|
| ① 유동성 | 10일 평균 거래량 50만 주 이상 · 20일 평균 거래대금 $5,000만 이상 |
| ② 변동성 | ADR(20일 평균 일중 변동폭) 2.5% 이상 |
| ③ 배열 | Lead |
| ④ 주도주 | 1개월 또는 3개월 수익률이 전체 상위 30% |
| ⑤ 주봉 | 주봉 종가 > 주봉 10 EMA, 10 EMA 상승 중 |
| ⑥ 눌림 + 겹침 | 최근 20일 고점에서 3~20% 조정 + **지지선 2개 이상이 겹친 구간**에 최근 2일 저가가 ±1.5% 안으로 닿음 |

**지지선 5종**: 9 EMA · 21 EMA · 50 EMA · **VWAP**(상승 시작 저점부터 앵커드 VWAP) · **전고**(돌파해서 지금 주가 아래에 있는 이전 고점)

| 단계 | 기준 |
|---|---|
| 📍 접근 중 | 지지선 2개 이상이 현재가 아래 5% 안에 모여 있음 (곧 도착) |
| 🎯 지지 도착 | 최근 2일 저가가 지지선 2개 이상에 닿음. **트리거 = 오늘 고가, 손절 = 최근 2일 저가**, 리스크 7% 이하 |
| ✅ 발동 | 어제 '지지 도착'이었고 오늘 어제 고가 위로 마감 |

**실적**: 지지 도착·발동 종목은 다음 실적 발표일을 조회해 표시합니다. 5일 이내면 ⚠️ (마틴 룩은 대부분 신규 진입을 피함) 표의 아래쪽으로 정렬됩니다.

## 표 보는 법

```
🎯 지지 도착
TICKER 겹친 지지선     고점%   1M%  ADR   트리거     손절 리스크  실적  이름
L3     21E+전고         -6.1   +10  3.6    82.50    79.70   3.5%  D-30  Lam
```

| 열 | 의미 |
|---|---|
| 겹친 지지선 | 닿은 지지선 조합. 많이 겹칠수록 좋은 자리 |
| 고점% | 최근 20일 고점 대비 |
| 1M% | 1개월 수익률 |
| ADR | 20일 평균 일중 변동폭(%) |
| 트리거 / 손절 / 리스크 | 내일 넘어야 할 가격(오늘 고가) / 손절가 / 그 거리 |
| 실적 | 다음 실적까지 일수 |

## 진단

Run workflow → system `pullback` → diagnose에 `NVDA, AMD`처럼 넣으면 분류([Lead] 등)와 단계 또는 탈락 이유가 옵니다.

## 설정 (`pullback.py` 맨 위)

| 항목 | 현재값 | 의미 / 조정 |
|---|---|---|
| `MIN_AVG_VOL` / `MIN_DOLLAR_VOL` | 50만 주 / $5,000만 | 유동성 |
| `ADR_MIN` | 2.5 | 원래 기준은 3.5. 대형주 위주라 완화. 결과가 너무 많으면 3.5 |
| `LEADER_PCT` | 70 | 1·3개월 수익률 백분위 (상위 30%) |
| `PB_MIN` / `PB_MAX` | 3 / 20 | 고점 대비 조정폭(%) |
| `BAND` | 1.5 | 지지선 닿음 오차(%) |
| `MIN_CONFLUENCE` | 2 | 겹쳐야 하는 지지선 수. 더 엄격하게는 3 |
| `APPROACH_MAX` | 5 | 접근 중 거리(%) |
| `RISK_MAX` | 7 | 최대 리스크(%) |
| `EARN_DAYS` | 5 | 실적 경고 일수 |
| `POTENT_ADR` / `POTENT_MOVE` | 3.5 / 0.5 | Potent 변동성 / 시가 대비 움직임(%) |

검색 대상이 S&P 500 + 관심종목이라 마틴 룩의 원래 대상(시가총액 1억 달러 이상 전 종목)보다 좁습니다. 소형 성장주를 더 보려면 `watchlist.txt`에 추가하세요.
