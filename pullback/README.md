# 강세주 눌림목 스캐너 (일봉)

S&P 500 + 관심종목(`watchlist.txt`) 약 690개에서 **먼저 크게 오른 강세주가 지지선으로 눌리면서 변동성이 응축되는** 종목을 찾아 디스코드로 보냅니다. 목표는 손절을 매수 지점 가까이 두고, 작은 비용으로 강세주의 다음 상승 구간을 노리는 것입니다. **한국 시각 평일(화~토) 아침 07:40쯤** 도착합니다 (GitHub 사정으로 5~30분 늦을 수 있음).

## 단계

| 단계 | 뜻 | 쓰임 |
|---|---|---|
| 📍 **접근 중** | 응축하면서 지지선 위 6% 이내까지 내려옴 | 곧 좋은 자리에 올 종목, 관심 목록에 넣어 두기 |
| 🎯 **지지 도착** | 최근 3일 안에 지지선 ±2%에 저점이 닿음 | 다음 날 **트리거가(오늘 고가)** 를 넘으면 진입 후보, 손절가·리스크 계산됨 |
| ✅ **발동** | 어제 '지지 도착'이었고 오늘 어제 고가 위로 마감 | 반등이 시작된 종목 |

## 조건 (모두 충족)

| 구분 | 조건 |
|---|---|
| ① 강세주 | RS 상위 20% (80 이상) · 선행 상승 +25% 이상 (최근 고점 ÷ 그 전 3개월 저점) · 52주 고점에서 25% 이내 · 주가 > 200일선 · 50일선 > 200일선 |
| ② 눌림 | 최근 30봉 안의 고점에서 3~25% 조정 · 고점은 2봉 이상 전 |
| ③ 지지선 | **상승 중인** 10EMA → 21EMA → 50일선 순서로 가장 가까운 선 (10봉 전보다 높은 선만) |
| ④ 응축 | 최근 5일 평균 변동폭(고가−저가) ÷ 50일 평균 **0.75 이하** · 최근 5일 평균 거래량 ÷ 50일 평균 **0.9 이하** |
| ⑤ 리스크 | 지지 도착 단계에서 트리거가 → 손절가 거리 **6% 이하** |
| 기본 필터 | 주가 $5 이상, 50일 평균 거래대금 $1,000만 이상, 상장 약 1년 이상 |

- **트리거가** = 오늘 고가 (내일 이 위로 올라가면 반등 시작)
- **손절가** = 최근 3일 저점과 지지선 −2% 중 낮은 값의 0.5% 아래

## 디스코드 알림 모양

```
🪜 강세주 눌림목 | 2026-10-30 마감
✅ 발동 1 · 🎯 지지 도착 2 · 📍 접근 중 1 (확인 690종목)

✅ 발동 · 어제 지지 도착 → 오늘 어제 고가 위 마감
TICKER 지지   고점%  응축 거래량     종가     손절 리스크  RS  이름
CRDO   21E     -8.4  0.53   1.58    96.11    91.42   5.1%  99  Credo

🎯 지지 도착 · 내일 트리거가(오늘 고가) 넘으면 진입 후보
TICKER 지지   고점%  응축 거래량   트리거     손절 리스크  RS  이름
ANET   21E     -9.6  0.44   0.75    92.18    89.11   3.4%  96  Arista

📍 접근 중 · 응축하며 지지선 위 6% 이내로 내려오는 중
TICKER 지지    지지가  거리%  고점%  응축 거래량  RS  이름
AMPX   50D      84.55   +5.7  -11.3  0.46   0.61  93  Amprius
```

| 열 | 의미 |
|---|---|
| 지지 | 10E = 10EMA, 21E = 21EMA, 50D = 50일선 |
| 고점% | 최근 고점 대비 현재 위치 |
| 응축 | 최근 5일 변동폭 ÷ 50일 평균. 작을수록 조용함 (0.5 이하면 매우 타이트) |
| 거래량 | 최근 5일 ÷ 50일 평균. 발동 표는 오늘 ÷ 50일 평균 (1 이상이면 거래량 실린 반등) |
| 트리거 / 종가 | 지지 도착 표는 다음 날 넘어야 할 가격, 발동 표는 오늘 종가 |
| 손절 | 손절가 |
| 리스크 | 트리거가(발동은 종가) → 손절가 거리 % |
| 지지가 / 거리% | 접근 중 표: 지지선 가격과 현재가가 그 위로 몇 % 떨어져 있는지 |

표는 RS 높은 순, 최대 25줄입니다.

## 종목 진단

**Run workflow** 창의 **진단할 티커** 칸에 `AMPX, NVDA`처럼 넣으면 단계 또는 탈락 이유가 옵니다.

```
AMPX 📍 접근 중 · 50일선 84.55 (거리 +5.7%) · 고점 대비 -11.3% · 선행 상승 +105% · 응축 0.46 · 거래량 0.61 · RS 93
NVDA ❌ 변동폭 응축 부족 (0.92 > 0.75) (RS 71)
```

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 생성 (예: `눌림목`) → ⚙ → 연동 → 웹후크 → 새 웹후크 → 채널이 새 채널인지 확인 → **웹후크 URL 복사**
2. **GitHub**: New repository (Public, 이름 예: `pullback-scanner`) → `pullback.py`, `watchlist.txt`, `requirements.txt`, `README.md` 업로드 → Commit
3. **Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` → zip 안의 같은 파일 내용을 붙여넣기 → Commit
4. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL` (직접 타이핑), Secret에 1번 웹후크 주소
5. **Actions → Pullback Scanner → Run workflow**로 테스트 (3~5분)

run-all의 `repos.txt`가 비어 있다면 자동으로 한꺼번에 실행 대상에 포함됩니다. 직접 적어 두었다면 `pullback-scanner`를 한 줄 추가하세요.

## 설정 바꾸기 (`pullback.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `RS_MIN` | 80 | RS 백분위 최소 |
| `RUN_MIN` | 25 | 선행 상승률 최소(%) |
| `NEAR_HIGH` | 25 | 52주 고점에서 이 % 이내 |
| `PB_MIN` / `PB_MAX` | 3 / 25 | 최근 고점 대비 조정폭 범위(%) |
| `HIGH_LOOKBACK` | 30 | 최근 고점을 찾는 기간(봉) |
| `TOUCH_PCT` / `TOUCH_BARS` | 2 / 3 | 지지선 터치 오차(%) / 최근 봉 수 |
| `APPROACH_MAX` | 6 | 접근 중으로 볼 지지선 위 거리(%) |
| `RANGE_MAX` | 0.75 | 변동폭 응축 기준. 더 타이트하게는 0.6 |
| `VOL_MAX` | 0.9 | 거래량 감소 기준. 더 엄격하게는 0.7 |
| `RISK_MAX` | 6 | 최대 리스크(%). 더 엄격하게는 4 |
| `MAX_ROWS` | 25 | 표마다 최대 줄 수 |
