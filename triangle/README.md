# 상승 삼각형·상승 수렴 스캐너

S&P 500과 내 관심종목에서 **고점을 잇는 위쪽 추세선**과 **저점을 잇는 더 가파른 아래쪽 추세선**이 위로 수렴하고, 주가가 위쪽 선 근처(돌파 직전 또는 막 돌파)에 있는 종목을 **일봉과 주봉 각각**에서 찾아 디스코드로 보냅니다. 매일 미국 장 마감 후 1회 실행됩니다.

## 패턴 유형

| TYPE | 모양 |
|---|---|
| **FLAT** | 위쪽 선이 거의 수평 (패턴 기간 상승폭 4% 이하). 교과서형 상승 삼각형 |
| **RISE** | 위쪽 선도 완만하게 오르고, 아래쪽 선이 더 가파르게 올라와 수렴 (BIIB·OSCR·OII 예시 모양) |

## 조건 (모두 충족해야 알림)

| 구분 | 조건 |
|---|---|
| 추세선 | 위쪽 선은 고점들 위에, 아래쪽 선은 저점들 아래에 그어지며 각각 고점·저점 **3개 이상**이 선의 ±2%(주봉 ±3%) 안에 닿음. 합계 6개 이상 |
| 위쪽 선 방향 | 수평이거나 상승. 2% 넘게 내려가면 제외 (하락 삼각형 배제) |
| 수렴 | 아래쪽 선이 위쪽 선보다 가파르고, 지금 두 선 간격이 패턴 시작 때의 **50% 이하** |
| 패턴 길이 | 일봉 60~250봉(약 3개월~1년), 주봉 52~156봉(약 1~3년) 중 가장 잘 맞는 길이 |
| 위치 | 종가가 위쪽 선 **아래 3% ~ 위 3%** 사이 |
| 깨끗함 | 패턴 중간에 위쪽 선을 크게 돌파한 적 없음 (최근 5봉은 예외), 아래쪽 선 이탈 마감이 5% 이하 |
| 상승 추세 | 일봉 기준 주가 > 200일선, 50일선 > 200일선 |
| 기본 필터 | 주가 $5 이상, 50일 평균 거래대금 $500만 이상, 상장 약 1년 이상 |

고점·저점은 일봉은 앞뒤 5봉, 주봉은 앞뒤 3봉보다 높은(낮은) 봉으로 자동 판별합니다.

## 디스코드 표 보는 법

| 열 | 의미 |
|---|---|
| TYPE | FLAT 또는 RISE |
| BARS | 패턴 길이 (일봉 표는 일, 주봉 표는 주) |
| HI / LO | 위쪽 선에 닿은 고점 수 / 아래쪽 선에 닿은 저점 수 |
| UPPER | 오늘 기준 위쪽 선 값 (돌파 기준가) |
| LAST | 종가 |
| POS% | 종가가 위쪽 선보다 몇 % 위(+)/아래(-)인지. 이 값이 0에 가까운 순으로 정렬 |
| SQZ% | 지금 두 선 간격 ÷ 시작 때 간격. 작을수록 꼭짓점에 가까움 |
| RS | 상대강도 (1~99) |
| VOLx | 패턴 기간 평균 거래량 ÷ 패턴 직전 50봉 평균. 1보다 작으면 거래량이 줄며 수렴 중 |

같은 종목·같은 시간 단위는 위쪽 선 가격이 3% 넘게 바뀌지 않는 한 15일 동안 다시 알리지 않습니다.

## 종목 진단 (왜 잡혔는지 / 안 잡혔는지)

1. **Actions** → **Ascending Triangle Scanner** → **Run workflow**
2. 펼쳐진 창의 **진단할 티커** 칸에 `BIIB, OSCR, OII`처럼 쉼표로 입력 → **Run workflow**
3. 디스코드에 종목별로 이렇게 옵니다.
   - `✅ 일봉 RISE · 200봉 · 고점 8회 · 저점 7회 · 위쪽 선 234.42 · 종가 233.35 (-0.5%)`
   - `❌ 일봉: 수렴 부족 (간격 17.8% → 13.2%) / 주봉: 추세선 터치 부족 (위 3, 아래 2)`

빈칸으로 실행하면 평소처럼 전체 스캔을 합니다. 관심종목에 없는 티커도 진단할 수 있습니다.

## 실행 시각

평일 한국 시각 **06:35** (미국 장 마감 후 확정 일봉 기준). GitHub 특성상 5~30분 늦을 수 있습니다.

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 → ⚙ → 연동 → 웹후크 → 새 웹후크 → URL 복사
2. **GitHub**: New repository (Public) → `triangle.py`, `watchlist.txt`, `requirements.txt`, `README.md` 업로드 → **Add file → Create new file**로 `.github/workflows/main.yml` 만들고 zip 안의 내용 붙여넣기
3. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL`, Secret에 웹후크 주소
4. **Actions → Ascending Triangle Scanner → Run workflow**로 테스트

이미 저장소가 있다면 `triangle.py`, `watchlist.txt`를 덮어쓰고, `.github/workflows/main.yml`을 zip 안의 내용으로 바꿔 주세요 (진단 칸이 추가됨).

## 설정 바꾸기 (`triangle.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `TIMEFRAMES` | 일봉 60~250봉, 주봉 52~156봉 | 시간 단위별 패턴 길이 후보, 고점·저점 판별 폭, 터치 오차 |
| `MIN_UPPER_TOUCH` / `MIN_LOWER_TOUCH` / `MIN_TOTAL_TOUCH` | 3 / 3 / 6 | 추세선 터치 최소 개수 |
| `MAX_UPPER_DROP` | 2 | 위쪽 선 하락 허용 한도(%) |
| `FLAT_PCT` | 4 | FLAT / RISE 구분 기준(%) |
| `SQUEEZE_RATIO` | 0.5 | 수렴 기준 |
| `NEAR_BELOW_PCT` / `NEAR_ABOVE_PCT` | 3 / 3 | 위쪽 선 기준 위치 범위(%) |
| `REQUIRE_TREND` | 1 | 상승 추세 조건 켜기(1)/끄기(0) |
| `REALERT_DAYS` | 15 | 재알림 금지 기간(일) |

## 알아둘 점

- 교과서에서는 위쪽 선까지 오르는 RISE 모양을 "상승 쐐기형"이라 부르고 하락 반전 신호로 보기도 합니다. 강한 상승 추세 종목에서는 위로 돌파하는 경우도 많아 함께 잡도록 했고, TYPE으로 구분됩니다.
- 무작위 가격 데이터로 시험했을 때 상승 추세 종목 중 일봉 약 5%, 주봉 약 2%가 패턴으로 잡혔습니다. 알림이 너무 많거나 적으면 터치 개수, `SQUEEZE_RATIO`, 위치 범위를 조정하세요.
- 시세는 야후 파이낸스 무료 데이터이고, 야후에 없는 티커는 빠집니다.
