# 아일랜드 갭 스캐너 (추세 전환)

S&P 500 + 관심종목 + ETF 목록에서 **아일랜드 리버설**이 최근 3봉 안에 완성된 종목을 찾습니다. 한국 시각 23:50(장중)과 07:10(마감 후)에 실행됩니다.

| 유형 | 모양 | 의미 |
|---|---|---|
| 🟢 아일랜드 바텀 | 갭 하락 → 아래에서 1~60봉 머묾 → 갭 상승 | 하락 → 상승 전환 |
| 🔴 아일랜드 톱 | 갭 상승 → 위에서 1~60봉 머묾 → 갭 하락 | 상승 → 하락 전환 |

## 조건

| 구분 | 기준 |
|---|---|
| 갭 | **완전 갭**만 인정 (꼬리끼리도 안 겹침). 두 갭 각각 0.5% 이상 |
| 고립 | 섬 안의 모든 봉이 양쪽 갭 바깥 봉들과 가격이 겹치지 않음 (바텀은 섬 전체가 아래, 톱은 위) |
| 시점 | 두 번째 갭이 최근 3봉 안에 생김 |
| 갭 유지 | 두 번째 갭 이후 가격이 섬 쪽으로 되돌아가 갭을 메우지 않음 |
| 기본 필터 | 주가 $5 이상, 50일 평균 거래대금 종목 $1,000만 / ETF $500만 이상 |

같은 종목에서 여러 길이의 섬이 가능하면 가장 짧은 섬을 씁니다.

## 디스코드 표

```
🟢 아일랜드 바텀 · 하락 → 상승 전환 · ETF
TICKER   섬   갭1%   갭2% 거래량  선행%             갭존     종가  이후%  이름
XBI     2봉   -3.1   +1.0    2.5   ⭐-4      64.28~64.95    69.95  +12.3  바이오
```

| 열 | 의미 |
|---|---|
| 섬 | 두 갭 사이 봉 수 |
| 갭1% / 갭2% | 섬으로 들어간 갭 / 섬에서 빠져나온 갭 (갭2 방향이 전환 방향) |
| 거래량 | 갭2 날 거래량 ÷ 50일 평균. 클수록 신뢰도↑ |
| 선행% | 섬 직전 20봉 등락. ⭐ = 반전 방향과 맞음 (바텀은 하락 후, 톱은 상승 후) |
| 갭존 | 두 갭이 겹치는 가격대. 바텀은 지지, 톱은 저항으로 봄 |
| 이후% | 섬 마지막 봉 종가 대비 지금 |

종목과 ETF는 표를 나눠 보내고, 최근에 완성된 순 → 갭2가 큰 순으로 정렬합니다.

## 진단

Run workflow에서 system `island`, diagnose에 `INTC, XBI`처럼 넣으면 현재 섬 여부와, 없으면 최근 120봉 안의 마지막 섬을 알려 줍니다.

## 설정 (`island.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `MAX_ISLAND` | 60 | 섬 최대 길이(봉) |
| `MIN_GAP` | 0.5 | 두 갭 각각 최소 크기(%). 잡음이 많으면 1로 |
| `RECENT_BARS` | 3 | 두 번째 갭이 최근 몇 봉 안에 생긴 것만 |
| `TREND_BARS` | 20 | 선행 추세 기간(봉) |
| `MIN_PRICE` / `MIN_DOLLAR_VOL` / `MIN_DOLLAR_VOL_ETF` | 5 / 1,000만 / 500만 | 기본 필터 |
| `MAX_ROWS` | 30 | 표마다 최대 줄 수 |
