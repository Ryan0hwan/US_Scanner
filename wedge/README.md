# 폴링 웻지 스캐너 (하락 쐐기)

S&P 500 + 관심종목 + ETF에서 **폴링 웻지**를 찾아, 표와 **두 추세선을 그린 캔들 차트 그림**으로 보냅니다.

## 찾는 방법

- 스윙 고점·저점(앞뒤 3봉, 2% 미만 잔물결 무시)을 찾고, 웻지 길이 30~180봉을 10봉 간격으로 모두 시도
- **위쪽 선**: 고점들 위에 그은 선 (모든 고점이 선 아래, ±1.5% 안이면 '터치')
- **아래쪽 선**: 저점들 아래에 그은 선

| 조건 | 기준 |
|---|---|
| 방향 | 두 선 모두 하락, **위쪽 선이 더 가파름** (간격이 좁아짐) |
| 하락폭 | 웻지 기간 위쪽 선이 8% 이상 하락 |
| 터치 | 위쪽 선 3번 이상, 아래쪽 선 2번 이상, 합계 6번 이상 |
| 수렴 | 지금 두 선 간격이 시작 때의 65% 이하 |
| 깨끗함 | 웻지 중간에 위쪽 선을 넘은 적 없음, 아래쪽 선 2% 넘게 깨고 마감한 봉 5% 이하 |

## 단계

| 단계 | 기준 |
|---|---|
| 🚀 돌파 | 최근 5봉 안에 위쪽 선 위로 마감, 지금도 선 위 (10% 넘게 멀리 간 종목 제외) |
| 🎯 돌파 임박 | 위쪽 선 아래 3% 이내 |
| 🔨 형성 중 | 두 선 사이 (기본은 꺼짐: `SHOW_FORMING`) |

- **목표가** = 웻지 시작 가격 (위쪽 선 출발점, 교과서식 목표)
- **손절** = 최근 10봉 저점 1% 아래
- **200일** 열: 200일선 위면 상승 추세 속 눌림(지속형), 아래면 하락 끝 반전 시도(반전형)

## 진단

Run workflow → **폴링 웻지** 체크 → diagnose에 티커

## 설정 (`wedge.py` 맨 위)

`WINDOWS`, `TOL`, `MIN_UPPER_TOUCH`, `MIN_LOWER_TOUCH`, `MIN_TOTAL_TOUCH`, `MIN_DECLINE`, `SQUEEZE`, `NEAR_PCT`, `SHOW_FORMING`, `IMG_MAX`, `REALERT_DAYS`. 결과가 너무 많으면 `MIN_TOTAL_TOUCH`를 7로, 적으면 `MIN_UPPER_TOUCH`를 2로.
