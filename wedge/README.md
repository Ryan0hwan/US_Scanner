# 폴링 웻지 스캐너 (하락 쐐기)

S&P 500 + 관심종목 + ETF에서 **폴링 웻지**를 찾아, 표와 **두 추세선을 그린 캔들 차트 그림**으로 보냅니다.

## 찾는 방법

- 스윙 고점·저점(앞뒤 3봉, 2% 미만 잔물결 무시)을 찾고, 웻지 길이 30~180봉을 10봉 간격으로 모두 시도
- **위쪽 선**: 고점들 위에 그은 선 (모든 고점이 선 아래, ±1.5% 안이면 '터치')
- **아래쪽 선**: 저점들 아래에 그은 선

| 조건 | 기준 |
|---|---|
| 방향 | 두 선 모두 하락, **위쪽 선이 더 가파름** (간격이 좁아짐) |
| 하락폭 | 웻지 기간 위쪽 선이 8% 이상 하락 |
| 터치 | 위쪽 선 3번 이상, 아래쪽 선 2번 이상, 합계 6번 이상 |
| 수렴 | 지금 두 선 간격이 시작 때의 65% 이하 |
| 깨끗함 | 웻지 중간에 위쪽 선을 넘은 적 없음, 아래쪽 선 2% 넘게 깨고 마감한 봉 5% 이하 |

## 단계

| 단계 | 기준 |
|---|---|
| 🚀 돌파 | 최근 5봉 안에 위쪽 선 위로 마감 + **돌파일 거래량 50일 평균의 1.3배 이상** (1.5배 이상은 🔥 표로 따로) + 돌파일 종가가 그날 범위 위쪽 절반, 지금도 선 위 (10% 넘게 멀리 간 종목 제외) |
| 🎯 돌파 임박 | 위쪽 선 아래 3% 이내 (기본은 꺼짐: `SHOW_NEAR`) |
| 🔨 형성 중 | 두 선 사이 (기본은 꺼짐: `SHOW_FORMING`) |

- **목표가** = 웻지 시작 가격 (위쪽 선 출발점, 교과서식 목표)
- **손절** = 최근 10봉 저점 1% 아래
- **200일** 열: 200일선 위면 상승 추세 속 눌림(지속형), 아래면 하락 끝 반전 시도(반전형)

## 🌊 소파동 섹션 (중파동 속 작은 웻지)

같은 메시지 안에 따로 표로 옵니다. 큰 추세 조건은 없어요.

| 조건 | 기준 |
|---|---|
| 웻지 길이 | 8~30봉 (2주~1.5달) |
| 고점·저점 | 앞뒤 2봉, 1.5% 미만 잔물결 무시 |
| 모양 | 두 선 모두 하락, 위쪽 선이 더 가파름, 위쪽 선 4% 이상 하락, 터치 위 2·아래 2 (합계 4) 이상, 간격 85% 이하로 수렴 |
| 돌파 | **최근 2봉 안** 위쪽 선 위 마감 + 돌파일 거래량 **50일 평균 1.2배 이상** + 종가가 그날 범위 위쪽 절반 + 선 위 6% 이내 |
| **5일선 꺾임** | 5일 이동평균이 **최근 3일 안에 하락 → 상승으로 전환**되고 지금도 상승 중 |

- 그림에는 웻지 두 선과 함께 **5일선(파란 선)**이 그려집니다 (최대 6장)
- 같은 작은 웻지는 10일 동안 다시 안 보냄
- 설정 (`wedge.py` 위쪽): `SMALL_ON`(켜기/끄기), `SMALL`(소파동 기준 묶음), `MA_LEN`(5 → 4로 바꾸면 4일선), `TURN_DAYS`(전환 인정 기간), `IMG_MAX_SMALL`

## 진단

Run workflow → **폴링 웻지** 체크 → diagnose에 티커

## 설정 (`wedge.py` 맨 위)

`WINDOWS`, `TOL`, `MIN_UPPER_TOUCH`, `MIN_LOWER_TOUCH`, `MIN_TOTAL_TOUCH`, `MIN_DECLINE`, `SQUEEZE`, `NEAR_PCT`, `SHOW_FORMING`, `IMG_MAX`, `REALERT_DAYS`. 결과가 너무 많으면 `MIN_TOTAL_TOUCH`를 7로, 적으면 `MIN_UPPER_TOUCH`를 2로.
