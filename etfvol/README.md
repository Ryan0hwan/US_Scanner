# ETF 특이 거래량 감시

`etfs.txt`의 ETF 105개를 **하루 1번, 미국 장 마감 후** 확인해서, **최근 3거래일** 거래량이 평소보다 크게 늘어난 ETF를 디스코드로 알려줍니다. **한국 시각 평일 아침 07:20쯤** 도착합니다 (GitHub 사정으로 5~30분 늦을 수 있음).

## 판정 방식

**배수 = 그날 거래량 ÷ 평소 거래량** (평소 = 3일 구간 바로 전 20거래일 평균)

| 조건 | 기준 |
|---|---|
| 알림 | 3일 평균 배수 1.5배 이상 **또는** 마지막 날 하루 2배 이상 |
| 거래 적은 ETF 제외 | 평소 하루 거래대금 $500만 미만 |

### 흐름 (3일 가격 + 거래량)

| 분류 | 기준 |
|---|---|
| 🟢 유입 | 3일 +0.5% 이상 상승 + 종가가 3일 고가권(위치 60 이상) + 거래량 실린 상승일 ≥ 거래량 실린 하락일 |
| 🔴 이탈 | 3일 −0.5% 이상 하락 + 종가가 3일 저가권(위치 40 이하) + 거래량 실린 하락일 ≥ 상승일 |
| ⚪ 혼조 | 그 외 (방향 없이 거래만 많음, 3일 안에서 반전 등) |

"거래량 실린 날" = 평소의 1.3배 이상인 날입니다.

### 거래량 패턴

| 패턴 | 뜻 | 해석 |
|---|---|---|
| 📶증가 | 3일 동안 매일 거래량이 늘어남 | 관심이 커지는 중, 가장 주목할 신호 |
| 🔁지속 | 3일 모두 1.3배 이상 | 며칠째 꾸준히 돈이 오감 |
| ⚡급증 | 앞 이틀은 평소 수준, 마지막 날만 2배 이상 | 새 이벤트, 하루짜리일 수 있음 |
| 🔻감소 | 거래량이 줄어드는 중 | 관심이 식는 중 |

## 디스코드 알림 모양

```
ETF 거래량 | 최근 3일(10/27~10/29) 마감 기준
3일 평균 1.5배 이상 또는 마지막 날 2배 이상 4개 (유입 1 · 이탈 1 · 혼조 2)

🟢 유입 (3일 상승 + 3일 고가권 + 거래량 실린 상승일이 더 많음)
TICKER   3일 10/27 10/28 10/29   3일% 위치 거래대금  패턴   설명
XLE      2.1   1.5   2.1   2.6   +4.6   81     551M  📶증가 에너지

🔴 이탈 (…)
KWEB     1.7   1.5   2.1   1.4   -4.4   22     447M  🔁지속 중국 인터넷

⚪ 혼조 (그 외)
SMH      1.7   2.2   1.3   1.5   +1.5   50     520M    ─    반도체
TLT      1.5   1.2   1.1   2.3   +0.0   33     486M  ⚡급증 미국채 20년+
```

| 열 | 의미 |
|---|---|
| 3일 | 3일 평균 배수 (큰 순으로 정렬) |
| 날짜 3칸 | 그날 하루 배수 |
| 3일% | 3일 전 종가 대비 등락 |
| 위치 | 3일 저가(0) ~ 고가(100) 중 마지막 종가 위치 |
| 거래대금 | 3일 합계 |

흐름은 가격과 거래량으로 추정한 것이고, 실제 ETF 설정·환매(자금 유출입) 데이터는 아닙니다. 해당 ETF가 없으면 "크게 늘어난 ETF 없음" 한 줄이 옵니다.

## 실행 시각

**한국 시각 평일(화~토) 07:20**, 하루 1회. 전날 미국장까지의 3거래일을 봅니다. 미국 장중에 수동으로 돌리면 아직 끝나지 않은 오늘은 빼고, 마감된 날까지만 분석합니다.

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 생성 (예: `etf-거래량`) → ⚙ → 연동 → 웹후크 → 새 웹후크 → 채널 확인 → URL 복사
2. **GitHub**: New repository (Public) → `etf_volume.py`, `etfs.txt`, `requirements.txt`, `README.md` 업로드 → **Add file → Create new file**로 `.github/workflows/main.yml` 만들고 zip 안의 내용 붙여넣기
3. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL`, Secret에 웹후크 주소
4. **Actions → ETF Volume Monitor → Run workflow**로 테스트 (1~2분). 언제 돌려도 마감된 최근 3거래일 기준으로 결과가 옵니다.

## ETF 추가·삭제

`etfs.txt`를 열어 `티커, 설명` 형식으로 한 줄씩 추가하거나 지우면 됩니다. 차트 목록에 있던 **SPX, SOX**는 지수라서 ETF처럼 거래량이 없어 뺐고, **ISAG**는 정확한 미국 티커를 확인하지 못해 주석으로 남겨 뒀습니다.

## 설정 바꾸기 (`etf_volume.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `DAYS` | 3 | 분석할 최근 거래일 수 |
| `LOOKBACK_DAYS` | 20 | 평소 거래량 비교 기간(거래일) |
| `RVOL3_MIN` | 1.5 | 3일 평균 배수 알림 기준 |
| `RVOL1_MIN` | 2.0 | 마지막 날 하루 배수 알림 기준 |
| `HIGH_DAY` | 1.3 | "거래량 실린 날" 기준 배수 |
| `FLOW_MIN` | 0.5 | 유입·이탈로 볼 최소 3일 등락(%) |
| `MIN_AVG_DOLLAR` | 5000000 | 거래 적은 ETF 제외 기준($) |
