# 바닥 반전 패턴 스캐너 (역헤드앤숄더 + 쌍바닥)

S&P 500 + 관심종목 + ETF에서 **역헤드앤숄더**와 **쌍바닥(이중 바닥)** 을 찾아, 표와 **패턴 선을 그린 캔들 차트 그림**으로 보냅니다. 차트 그림을 보는 게 아니라 매일의 고가·저가·종가 숫자로 계산합니다.

## 찾는 방법

1. **스윙 저점·고점**: 앞뒤 4봉보다 낮은(높은) 날. 3% 미만 잔물결은 무시
2. **역헤드앤숄더**: 저점 3개(왼어깨·머리·오른어깨) + 그 사이 반등 고점 2개를 이은 **넥라인**
3. **쌍바닥**: 높이가 비슷한 저점 2개 + 가운데 고점(수평 **넥라인**)

| 조건 | 역헤드앤숄더 | 쌍바닥 |
|---|---|---|
| 모양 | 머리가 두 어깨보다 3% 이상 낮음, 두 어깨 높이 차이 10% 이내, 좌우 기간 비율 3배 이내, 넥라인 기울기 12% 이내 | 두 바닥 높이 차이 3% 이내, 간격 10~150봉 |
| 패턴 높이 | 넥라인~최저점 8% 이상 | 같음 |
| 앞의 하락 | 패턴 시작 전 60봉 안에서 10% 이상 하락 (바닥 반전이므로) | 같음 |
| 최근성 | 오른쪽 어깨가 최근 30봉 안 | 두 번째 바닥이 최근 30봉 안 |
| 깨지지 않음 | 오른쪽 어깨(두 번째 바닥) 이후 3% 넘게 더 낮은 저점 없음 | 같음 |

## 단계

| 단계 | 기준 |
|---|---|
| 🚀 돌파 | 최근 5봉 안에 넥라인 위로 처음 마감, 지금도 넥라인 위 (10% 넘게 멀리 간 종목 제외) |
| 🎯 돌파 임박 | 넥라인 아래 5% 이내 |
| 🔨 형성 중 | 넥라인 아래 12% 이내 + 오른쪽 바닥에서 3% 이상 반등 (기본은 꺼짐: `SHOW_FORMING`) |

- **목표가** = 넥라인 + 패턴 높이 (교과서식 측정 목표)
- **손절** = 오른쪽 어깨(두 번째 바닥) 저점 1% 아래
- 같은 종목·패턴·단계는 10일 동안 다시 알리지 않음. 임박 → 돌파로 바뀌면 다시 알림

## 디스코드

```
역헤드앤숄더 · 🚀 돌파
TICKER    넥라인     종가  거리%   목표가 목표%     손절 높이%   봉 거래량  이름
IHS2       92.94    93.18   +0.3   112.65   +21    79.75    27   54    2.0  …
```
돌파·임박 종목은 패턴별 최대 8장, 왼어깨·머리·오른어깨(바닥1·바닥2)와 넥라인·목표·손절 선을 그린 차트 그림이 같이 옵니다.

## 진단

Run workflow → **바닥 패턴** 체크 → diagnose에 티커 → 두 패턴 각각 잡혔는지, 아니면 어디서 빠졌는지 + 그림

## 설정 (`bottoms.py` 맨 위)

`HEAD_DEPTH`, `SHOULDER_TOL`, `DB_TOL`, `MIN_HEIGHT`, `PRIOR_DROP`, `RECENT_LAST_LOW`, `NEAR_PCT`, `SHOW_FORMING`, `IMG_MAX`, `REALERT_DAYS` — 각 줄 옆에 설명이 있습니다. 결과가 너무 많으면 `MIN_HEIGHT`를 10~12로, 적으면 `DB_TOL`을 4로 올리세요.
