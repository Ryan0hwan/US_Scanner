# 장기 베이스 스캐너 (2년+ 컵앤핸들·박스)

S&P 500 + 관심종목(`watchlist.txt`) + ETF(`etfs.txt`)를 **주봉**으로 보고, 2년 이상 바닥을 다진 종목을 찾습니다.

## 오는 내용

| 섹션 | 조건 |
|---|---|
| 🚀 베이스 돌파 (1달 이내) | 2년 이상 베이스의 천장을 **주봉 종가로 1% 이상** 뚫었고, 돌파한 날로부터 **21거래일(약 1달) 안** |
| 🧱 베이스 진행 중 | 2년 이상 베이스 안에 있고, 현재가가 천장 아래 **15% 안**까지 올라옴 |

종목마다 주봉 캔들 그림(천장 빨간 점선, 바닥 초록 점선, 베이스 시작·돌파 표시)이 같이 옵니다.

## 베이스 판정 (주봉 숫자로 계산)

| 항목 | 기준 |
|---|---|
| 기간 | 104주(2년) ~ 260주(5년) 중 조건을 만족하는 가장 긴 기간 |
| 천장 | 그 기간 최고 **주봉 종가** (윗꼬리 무시) |
| 천장 터치 | 고가가 천장 -7% 안에 2번 이상. 첫 터치는 기간 앞쪽 40% 안, 첫~마지막 터치 1년 이상 차이 |
| 깊이 | 천장 대비 최저가 15~65% 아래 |
| 최저점 위치 | 기간 맨 앞·맨 끝이 아님 (하락 추세 중인 종목 제외) |
| 튄 적 | 기간 중 고가가 천장 +15%를 넘은 적 없음 |

## 모양 이름

| 이름 | 뜻 |
|---|---|
| 박스 | 천장 3번 이상 + 바닥 2번 이상 터치 |
| 컵앤핸들 | 가운데가 깊은 U자 + 오른쪽 끝에서 천장 근처를 찍고 5~30% 짧게 눌림 |
| 컵 | 가운데가 깊은 U자 (손잡이 없음) |
| 베이스 | 그 외 장기 횡보 |

## 표 읽는 법

| 열 | 뜻 |
|---|---|
| 천장 | 베이스 천장 (저항) 가격 |
| 천장대비 / 천장까지 | 현재가가 천장보다 몇 % 위/아래. ⚠ = 돌파 후 다시 천장 아래로 내려옴 |
| 돌파일 / 경과 | 일봉 종가가 처음 천장 위로 간 날 / 그 뒤 지난 거래일 |
| 기간 | 베이스 길이(년) |
| 깊이 | 천장 대비 바닥이 몇 % 아래였나 |
| 거래량 | 돌파 주 거래량 ÷ 직전 10주 평균 (이번 주 진행 중이면 하루 평균으로 환산) |
| 터치 | 천장에 닿은 횟수 |

## 실행

- 자동: 평일 한국 **07:10** 하루 1번 (주봉 기준이라 23:50 장중 회차는 건너뜀)
- 같은 돌파는 35일 동안 다시 안 보냄. 진행 중 목록은 같은 종목을 1주일에 한 번씩 다시 보여줌
- 수동 진단: Run workflow → `base` 체크 → diagnose에 `ZETA, NVDA` → 왜 잡혔는지/안 잡혔는지 이유가 옴

## 설정 (`base.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `MIN_WEEKS` | 104 | 베이스 최소 길이(주) |
| `MAX_WEEKS` | 260 | 베이스 최대 길이(주) |
| `MIN_DEPTH` / `MAX_DEPTH` | 15 / 65 | 바닥 깊이 % 범위 |
| `BO_DAYS` | 21 | 돌파 후 며칠(거래일)까지 보여줄지 |
| `BO_VOL_MIN` | 0 | 돌파 주 거래량 최소 배수 (0 = 조건 없음. 거래량 실린 돌파만 원하면 1.5) |
| `NEAR_PCT` | 15 | 진행 중: 천장 아래 몇 % 안까지 보여줄지 |
| `IMG_MAX_BO` / `IMG_MAX_BASE` | 8 / 5 | 그림 최대 장 수 |
